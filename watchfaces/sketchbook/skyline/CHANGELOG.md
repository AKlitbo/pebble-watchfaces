# Changelog - Skyline

All notable changes to the Skyline watchface are documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.2] - 2026-10-16

### Notes

- Skyline is no longer being updated. Sketchbook Horizon replaces it, bringing this scene and three others into one watchface you can switch between in settings. This release adds a note to the settings page with a link to it, and nothing else changes.

## [1.0.1] - 2026-10-15

### Changed

- On a round Pebble, each palette picture in the Scene Palette picker is shown as a round preview that matches the screen.

### Fixed

- Fixed the palette pictures in the Scene Palette picker looking rough in the settings page.

## [1.0.0] - 2026-10-14

### Added

- First release of the Skyline watchface.
